# Быстрый старт с Microsoft Teams

## ✅ Готово!

UI для Microsoft Teams добавлен в веб-интерфейс.

## Как использовать:

### 1. Зарегистрируйте приложение в Azure AD

Следуйте инструкции в `TEAMS_INTEGRATION.md` (раздел "Регистрация приложения в Azure AD")

Важно:
- **Redirect URI**: `http://localhost:8000/api/teams/callback`
- **Permissions**: `Calendars.ReadWrite`, `User.Read` (Delegated, НЕ Application!)
- **НЕ НУЖЕН** Admin Consent

### 2. Откройте веб-интерфейс

```bash
# Если сервер не запущен
./scripts/run_web.sh

# Откройте браузер
http://localhost:8000
```

### 3. Настройте Teams

1. Перейдите на вкладку **⚙️ Настройки**
2. Прокрутите до секции **🟣 Microsoft Teams**
3. Заполните:
   - **Client ID**: Application (client) ID из Azure AD
   - **Client Secret**: Secret value (не ID!)
4. Нажмите **💾 Сохранить**

### 4. Авторизуйтесь

1. Нажмите **🔐 Авторизовать Teams**
2. Откроется новое окно браузера
3. Войдите под своей учеткой Microsoft
4. Разрешите доступ к календарю
5. Окно закроется автоматически

### 5. Проверьте подключение

1. Нажмите **✓ Тест**
2. Должны увидеть:
   ```
   ✅ Подключение к MS Teams успешно
   Пользователь: ваш_email@company.com
   Имя: Ваше Имя
   Календарь: Calendar
   ```

### 6. Настройте синхронизацию

1. Перейдите на вкладку **🔄 Синхронизация**
2. В разделе "Источники для синхронизации":
   - ✅ 🔵 Google Calendar
   - ✅ 🟠 Lotus Notes/Domino
   - ✅ 🟣 Microsoft Teams ← включите!
3. Выберите направление (например, "Все источники")
4. Нажмите **▶ Запустить**

## Маркеры событий

События автоматически помечаются источником:
- `[GC]` - событие из Google Calendar
- `[LN]` - событие из Lotus Notes/Domino
- `[MT]` - событие из Microsoft Teams

**Важно**: События с маркерами НЕ синхронизируются обратно в другие системы!

Пример:
- ✅ Создали "Meeting" в Google → синхронизируется в Teams как "[GC] Meeting"
- ❌ "[GC] Meeting" из Teams → НЕ пойдет обратно в Google (уже имеет маркер)

## Troubleshooting

**Ошибка "Требуется авторизация"**:
- Нажмите "🔐 Авторизовать Teams" и войдите под своей учеткой

**Ошибка "Redirect URI mismatch"**:
- Проверьте что в Azure AD указан ТОЧНО: `http://localhost:8000/api/teams/callback`

**Окно авторизации не открывается**:
- Проверьте что браузер не блокирует popup окна
- Скопируйте URL вручную из консоли браузера (F12)

**События не синхронизируются**:
- Убедитесь что чекбокс "🟣 Microsoft Teams" включен
- Проверьте логи на вкладке "📋 Логи"
