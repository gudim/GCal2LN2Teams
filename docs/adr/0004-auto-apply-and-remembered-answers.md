# Автоприменение и запомненные ответы

Это дополнение к ADR 0003, только для мобильного приложения. Когда всё настроено и синхронизация идёт регулярно, подтверждать каждое создание, перенос, обновление и удаление утомительно. Поэтому после первого ручного применения ручная синхронизация работает как фоновая: выполняет всё, кроме вопросов, сразу. Если вопросы остались, приложение строит предпросмотр заново и показывает только их. Отчёт объединяет оба шага. Прежнее поведение включается настройкой «Подтверждать каждое действие», по умолчанию она выключена. Полный предпросмотр без применения (там же список «Не копируется») остаётся доступен отдельной кнопкой.

Первое ручное применение по-прежнему идёт через полный предпросмотр: на нём пользователь отказывается от лишних копий (ADR 0003). Установки из прежних версий, где фон уже настроен, считаются прошедшими его.

Вопрос «правка встречи с участниками» раньше задавался заново при каждом изменении встречи: снятая галочка значила «не сейчас». Теперь ответ («да» или «нет») запоминается по ключу действия `update:<система>:<id>` вместе с названием встречи. Пока название то же и правка его не меняет, ответ применяется сам, в том числе фоновой синхронизацией: «да» — правка выполняется без вопроса, «нет» — правки нет. Если название меняется, вопрос задаётся снова. Ответы хранятся в настройках (DataStore), а не в базе связей: миграций у базы нет. Забыть их можно в настройках.

Остальные вопросы уже запоминаются связями (`kept`, `distinct`, отказ от копирования). Удаления при подозрении на массовое удаление задаются всегда: это защита от сбоя сервера, автоматизировать её нельзя.

## Considered Options

- **Автоприменение и для первого запуска.** Отклонено: тогда скопировалось бы то, от чего пользователь ещё не успел отказаться (ADR 0003).
- **Применить и показать вопросы из одного плана.** Отклонено: план выполняется один раз, а повторное применение части уже выполненного плана расходится с записанными связями. План строится заново, это ещё одно чтение календарей, но только когда вопросы есть.
- **Запоминать ответ без условия на название.** Отклонено: смена названия — заметная правка, которую участники увидят в письме, о ней стоит спросить снова.

## Consequences

- Ручной запуск с вопросами читает календари дважды.
- Запомненный «нет» скрывает правку и из полного предпросмотра; вернуть вопрос можно, забыв ответы в настройках.
- Ответы копятся по одному на встречу; список не чистится, пока пользователь его не сбросит.
