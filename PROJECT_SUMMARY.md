## 📋 Что включено в план

### 🏗️ Архитектура
- Модульная структура с разделением на адаптеры, синхронизатор, БД
- Кроссплатформенность (Windows/Linux)
- CLI интерфейс на базе Click
- SQLite база данных для хранения маппинга и истории

### 🔧 Технологии
- **Google Calendar API** - полная интеграция
- **Lotus Notes** - через pywin32 (Windows) и Wine (Linux)
- **SQLAlchemy** - ORM для работы с БД
- **APScheduler** - автоматическая синхронизация
- **Click** - красивый CLI

### 🔄 Функциональность
1. **Двусторонняя синхронизация** (Google ↔ Lotus)
2. **Односторонние варианты** (Google → Lotus или Lotus → Google)
3. **Разрешение конфликтов** - 5 стратегий:
   - Manual (ручное)
   - Google wins
   - Lotus wins
   - Latest wins (по timestamp)
   - Merge (объединение)
4. **Фильтры событий**
5. **Автоматический запуск** (службы/демоны)
6. **Детальное логирование**

### 📊 База данных
Схема включает:
- `event_mapping` - маппинг событий между системами
- `sync_log` - история синхронизаций
- `conflicts` - неразрешенные конфликты

## 🚀 Как начать использовать

### 1. Клонировать репозиторий
```bash
git clone <repository-url>
cd gcaltolotus
```

### 2. Установить зависимости
```bash
python3 -m venv venv
source venv/bin/activate  # Linux
# или venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

### 3. Настроить Google Calendar
- Создать проект в Google Cloud Console
- Включить Calendar API
- Скачать credentials.json

### 4. Настроить конфигурацию
```bash
cp config/config.yaml.example config/config.yaml
cp .env.example .env
```

### 5. Запустить авторизацию
```bash
bash scripts/setup_google_auth.sh  # Linux
# или scripts\setup_google_auth.bat  # Windows
```

### 6. Первая синхронизация
```bash
pip install -e .
gcalsync sync --dry-run
```
