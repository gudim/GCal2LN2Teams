Summary

GCalSyncLNTeams copies calendar events between your Google Calendar, your HCL Notes/Domino calendar and your Microsoft Teams/Outlook calendar. It runs entirely on your phone. The developer operates no server, collects no analytics and receives none of your data.

Data the app accesses

  • Google Calendar (scopes calendar and calendar.events): the list of your calendars, and events in the selected calendar within the sync window (title, start and end time, location, description, organizer). The app creates, updates and deletes events in that calendar to keep it in sync, and can create a new calendar when you ask it to.
  • Microsoft Teams/Outlook (Microsoft Graph scopes Calendars.ReadWrite, User.Read, offline_access): the same event fields in your default calendar, and your account name to show which account is signed in.
  • HCL Notes/Domino: the same event fields in your mail-file calendar, using the server address, user name and password you enter.

How the data is used

Event data is used only to copy events between your own calendars and to show you a preview of the changes. It is not used for advertising, profiling, or any other purpose, and it is not sold or shared with anyone.

Where the data is stored

  • Events stay in your calendars. The app keeps, on the phone only, a table of links between an event and its copies (event IDs and the title, time, location and description at the last sync) so that it can tell what changed.
  • Sign-in tokens and the Domino password are stored on the phone, encrypted with a key held in the Android Keystore. They are excluded from device backups.
  • Uninstalling the app deletes all of this data. Signing out in the app deletes the stored tokens.

Data sharing and transfer

The app sends data only to the services you connect: Google Calendar API, Microsoft Graph, and your Domino server, over HTTPS. Once a week the app asks the public GitHub API whether a newer version has been released; this request contains no personal data. No other third parties receive data.

Google API Services User Data Policy

GCalSyncLNTeams' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the calendar sync you request, is not transferred to anyone else, is not used for advertising, and is not read by humans.

Revoking access

You can sign out in the app at any time, revoke Google access at myaccount.google.com/permissions, and revoke Microsoft access at myapps.microsoft.com.

Children

The app is a work tool and is not directed at children.

Changes and contact

Changes to this policy are published on this page. Questions: GitHub issues.

Политика конфиденциальности (русская версия)

GCalSyncLNTeams копирует события между вашими календарями Google, HCL Notes/Domino и Microsoft Teams/Outlook. Приложение работает только на телефоне. У разработчика нет сервера, аналитика не собирается, ваши данные разработчику не передаются.

К каким данным приложение обращается

  • Google Календарь (доступы calendar и calendar.events): список ваших календарей и события выбранного календаря в окне синхронизации (название, начало и конец, место, описание, организатор). Приложение создаёт, меняет и удаляет события в этом календаре и по вашей просьбе может создать новый календарь.
  • Microsoft Teams/Outlook (Microsoft Graph: Calendars.ReadWrite, User.Read, offline_access): те же поля событий в основном календаре и имя учётной записи.
  • HCL Notes/Domino: те же поля событий в календаре почтового файла; адрес сервера, логин и пароль вводите вы.

Как данные используются

Только чтобы копировать события между вашими календарями и показывать предпросмотр изменений. Данные не используются для рекламы или профилирования, не продаются и никому не передаются.

Где хранятся данные

  • События остаются в ваших календарях. На телефоне приложение хранит только таблицу связей между событием и его копиями (идентификаторы и название, время, место, описание на момент последней синхронизации).
  • Токены входа и пароль Domino хранятся на телефоне в зашифрованном виде (ключ в Android Keystore) и не попадают в резервные копии.
  • Удаление приложения удаляет все эти данные; выход из учётной записи в приложении удаляет токены.

Передача данных

Данные уходят только в подключённые вами сервисы по HTTPS: Google Calendar API, Microsoft Graph и ваш сервер Domino. Раз в неделю приложение спрашивает у публичного API GitHub, не вышла ли новая версия; в этом запросе нет личных данных.

Данные Google

Использование и передача информации, полученной через Google API, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Выйдите из учётной записи в приложении или отзовите доступ: Google — myaccount.google.com/permissions, Microsoft — myapps.microsoft.com.
