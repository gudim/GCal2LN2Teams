# ⚠️ Решение ошибки "403: access_denied" - Google OAuth

## Проблема

При попытке авторизации появляется ошибка:
```
Мы пока не проверили приложение "GCalSync". Сейчас оно тестируется 
и им могут пользоваться только одобренные разработчиком тестировщики.

Ошибка 403: access_denied
```

## Причина

Приложение находится в режиме тестирования и требует добавления пользователей в список тестировщиков.

---

## ✅ Решение (2 варианта)

### Вариант 1: Добавить себя в тестировщики (Рекомендуется)

#### Шаг 1: Откройте Google Cloud Console
1. Перейдите на https://console.cloud.google.com/
2. Выберите ваш проект (GCalSync)

#### Шаг 2: Откройте OAuth consent screen
1. В левом меню: **APIs & Services** → **OAuth consent screen**
2. Или прямая ссылка: https://console.cloud.google.com/apis/credentials/consent

#### Шаг 3: Добавьте тестового пользователя
1. Прокрутите вниз до секции **Test users**
2. Нажмите **+ ADD USERS**
3. Введите ваш email адрес (тот, которым входите в Google)
4. Нажмите **SAVE**

#### Шаг 4: Попробуйте снова авторизоваться
```bash
# Удалите старый токен если есть
rm -f data/google_token.pickle

# Запустите авторизацию заново
python -m src.main init
```

**Готово!** Теперь вы в списке тестировщиков и авторизация должна пройти успешно.

---

### Вариант 2: Опубликовать приложение (Для production)

⚠️ **Внимание:** Это требуется только если планируете использовать приложение публично.

#### Шаг 1: Заполните OAuth consent screen
1. **APIs & Services** → **OAuth consent screen**
2. Нажмите **EDIT APP**
3. Заполните все обязательные поля:
   - App name: GCalSync
   - User support email: ваш email
   - App logo (опционально)
   - App domain (опционально для тестирования)
   - Authorized domains (опционально)
   - Developer contact information: ваш email

#### Шаг 2: Настройте Scopes
1. Перейдите на вкладку **Scopes**
2. Нажмите **ADD OR REMOVE SCOPES**
3. Найдите и добавьте:
   - `.../auth/calendar` - See, edit, share, and permanently delete all the calendars you can access using Google Calendar
   - `.../auth/calendar.events` - View and edit events on all your calendars
4. Нажмите **UPDATE**

#### Шаг 3: Отправьте на верификацию
1. Вернитесь на **OAuth consent screen**
2. Нажмите **PUBLISH APP**
3. Подтвердите публикацию

**Примечание:** Для полной публикации может потребоваться верификация Google (занимает несколько дней).

## ❓ Часто задаваемые вопросы

### В: Какой email добавлять?
**О:** Тот email, которым вы входите в Google Calendar. Обычно это ваш Gmail адрес.

### В: Можно добавить несколько тестировщиков?
**О:** Да! Нажимайте "+ ADD USERS" для каждого нового email.

### В: Сколько можно добавить тестировщиков?
**О:** До 100 пользователей в режиме тестирования.

### В: Нужно ли верифицировать приложение?
**О:** Нет, если используете только для себя и список тестировщиков < 100 человек.

### В: Что делать если появляется "This app isn't verified"?
**О:** Это нормально для dev приложений:
1. Нажмите "Advanced"
2. Нажмите "Go to GCalSync (unsafe)"
3. Это безопасно, так как это ваше приложение

### В: Изменения не применяются?
**О:** Подождите 1-2 минуты после добавления в тестировщики, иногда требуется время на синхронизацию.
